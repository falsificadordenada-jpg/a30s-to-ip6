# Patches do A30s sobre o xnu-4903

Coloque aqui `NNNN-nome.patch` (formato `git diff`) e/ou `NNNN-nome.sh`. Rodam em ordem
alfabetica logo depois do download do xnu. Se um patch nao aplicar, o build PARA (de proposito).
Este repo guarda so os NOSSOS patches; o codigo da Apple e baixado a cada build (nao e copiado aqui).
